# Security Policy

KingSec is a security product; we hold ourselves to the standard we ask of others.

## Reporting a vulnerability
Please report suspected vulnerabilities privately to **security@kingsec.example** *(placeholder - replace with the real intake address before release)*.

- Do **not** open a public issue for security reports.
- Include steps to reproduce, affected version/commit, and impact.
- We aim to acknowledge within a few business days and to keep you updated through remediation.

## Scope
This policy covers the KingSec application and its official distribution. Testing must only target systems you are authorized to assess - the same authorization principle the product enforces.

## Disclosure
We follow coordinated disclosure: please give us a reasonable window to remediate before any public discussion.
