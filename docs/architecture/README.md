# Architecture Decision Records (ADRs)

This directory records the *why* behind significant, hard-to-reverse decisions.
Each ADR is a short, immutable document; superseding a decision means adding a new
ADR that references the old one, never editing history.

Recommended file name: `NNNN-short-title.md` (e.g. `0001-hexagonal-architecture.md`).
