## Bug Reports & Feature Requests

**GitHub Issues:** https://github.com/kingusecurity/kingsec/issues

Please use the GitHub issue tracker to:
- Report bugs or unexpected behavior
- Suggest new features or improvements
- Submit scanner integration requests
- Report documentation errors

Before opening a new issue, search existing issues to avoid duplicates. Include your KingSec version, deployment method (Docker or pip), and relevant log output when reporting bugs.

---

## Feature Request Process

1. **Check existing requests** — Search the GitHub issue tracker to see if your feature has already been suggested.
2. **Open a new issue** — Use the "Feature Request" template. Describe the problem you want to solve and how the feature would work.
3. **Discussion** — The maintainer and community may ask clarifying questions or suggest alternatives.
4. **Implementation** — Accepted features are added to the roadmap. Timelines are provided where possible.

Feature requests related to new scanners, additional AI providers, and report format extensions are particularly welcome.
