# KingSec Branding Guidelines

**Version:** 1.0  
**Last Updated:** 2026-07-27

## Logo

### Primary Logo
The KingSec logo consists of the KingSec wordmark. No icon is used.

### Clear Space
Maintain clear space equal to the height of the "K" on all sides of the logo.

### Minimum Size
- Digital: 120px width minimum
- Print: 1 inch width minimum

### Incorrect Usage
- Do not stretch or distort the logo
- Do not change the logo colors
- Do not add effects (shadows, gradients, outlines)
- Do not place on low-contrast backgrounds
- Do not rotate the logo

## Typography

### Primary Font: Inter
- Available from Google Fonts
- Weights: 400 (Regular), 500 (Medium), 600 (Semibold), 700 (Bold)
- Used for all UI text, headings, and body copy

### Monospace Font: JetBrains Mono
- Available from Google Fonts
- Weights: 400 (Regular), 500 (Medium)
- Used for code blocks, API responses, terminal output

### Type Scale
| Level | Size | Weight | Usage |
|-------|------|--------|-------|
| H1 | 24px | 700 | Page titles |
| H2 | 18px | 600 | Section headings |
| H3 | 14px | 600 | Card titles |
| Body | 14px | 400 | Paragraph text |
| Small | 12px | 400 | Labels, metadata |
| Caption | 11px | 500 | Badges, timestamps |

## Icon Style

- Use stroke-based icons (Lucide icon set)
- Stroke width: 1.5px
- Icon size: 16px (standard), 20px (standalone), 24px (hero)
- Maintain consistent visual weight across all icons
- Icons should be semantically meaningful, not decorative

## Spacing

- Base unit: 4px
- Standard padding: 16px (4 units)
- Section spacing: 24px (6 units)
- Page margins: 24px

## Screenshot Guidelines

### Resolution
- Capture at 1920x1080 or 1440x900
- Use the browser's full viewport
- No browser chrome (use browser dev tools to hide)

### Format
- PNG format for screenshots
- JPEG for hero images (if needed for file size)

### Content
- Use realistic but anonymized data
- No personal information
- Consistent demo environment (same target, same assessment)

### Style
- Dark theme only (matches the product UI)
- No redaction boxes or arrows in raw screenshots
- Annotations are separate overlay files

## Report Branding

### Cover Page
- Report title: "Security Assessment Report"
- Target name and date
- Executive score displayed prominently
- "Generated by KingSec" footer

### Color Usage in Reports
- Same severity color scheme as the product
- Professional monochrome for print-friendly PDFs
- Accent blue for headings and section dividers

### Font in Reports
- Body: Inter or system sans-serif
- Headings: Inter Bold
- Code/technical: JetBrains Mono

## Voice and Tone

### Principles
- **Clear:** Simple language, avoid jargon where possible
- **Honest:** Acknowledge limitations, no fear-based messaging
- **Professional:** Technical accuracy, proper grammar
- **Helpful:** Focus on solutions and guidance

### Do
- Use active voice
- Be specific about capabilities
- Acknowledge when something is a limitation

### Don't
- Exaggerate capabilities
- Use fear-based language about security risks
- Make unsubstantiated claims about competitor products
- Use vague marketing terminology
