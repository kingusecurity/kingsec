5. MEDIUM ISSUES
==========================================================================
1. AssessmentsPage search/status/sort controls update the URL but do
   nothing — the backend has no matching filter/sort parameters at all
   (list_assessments only accepts limit/offset). Closing this requires
   new backend capability.
2. No bundled production hosting for the frontend — the backend never
   serves frontend/dist/ (confirmed no StaticFiles mount; GET / -> 404).
   Operators must self-host behind a reverse proxy (already documented
   in INSTALL.md).
3. Plugin ZIP install and the full agent-driven job-completion path have
   not been exercised live in this engagement — unverified, not
   confirmed broken.
